# Square logo assets

Upload these in **Square Dashboard → Account & settings → Business → Locations → Pinkney Park**:

| File | Use |
|------|-----|
| `public/images/square-checkout/logo-framed-800.jpg` | Framed / square logo (800×800) |
| `public/images/square-checkout/logo-full-width-1280.jpg` | Full-width checkout header (1280×648) |

Checkout branding is set to **FULL_WIDTH_LOGO** + navy button via `npm run brand:square-checkout`.

After uploading the full-width logo in Square, refresh any Payment Link to see the larger header.
